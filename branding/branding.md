# Kolam Makers Branding Kit

## Name

**Kolam Makers**

**Rationale:**
- *Makers* connects to a recognised global movement (makerspaces, FabLabs, hackerspaces).
- *Kolam* anchors the class in its place (Kolam Ayer CC) and carries cultural depth in Tamil and Malay communities (kolam = a geometric pattern art form; ayer = water in Malay).
- Future-proof: as the permanent club grows beyond Linux into AI, homelab, electronics, and networking. The name still fits.

---

## Slogan

**Build. Break. Repeat.**

## Logo

### Concept

The Kolam Makers logo combines traditional kolam-inspired symmetry with a hacker/maker visual language: looping geometric linework and dot patterns frame the name like a crafted ornamental circuit, while the rough brush typography gives it a hands-on, workshop energy rather than a polished corporate feel. The >_ shell prompt signals Linux, coding, and command-line culture, and the binary 01001011 01001101 subtly encodes "KM" for Kolam Makers. The teal, orange, black, and lime accents keep it technical and vibrant, while the mirrored top and bottom patterns reinforce the kolam concept of balance, repetition, and constructed beauty.

### Variants

- **Full colour (main)**
- **Inverted (light backgrounds)**
- **ANSI (for motd, IRC topic):** see below.

### ANSI version for the server login motd

```
./branding/kolam-makers-ansi.sh
```

The script is dependency-free and uses truecolor ANSI escape sequences plus
Unicode block and line art for a terminal-friendly version of the logo.

## Usage rules

- The slogan is optional. Don't put it on every surface. It gets noisy.
- Abbreviations OK: `km` (lowercase) or `KM` (uppercase). **Never** `KAM` (looks like a different acronym).
- Avoid using the GNU/Linux Tux penguin in primary branding. We're makers, not just Linux users. Tux can appear as an Easter egg in motd or slide deck.

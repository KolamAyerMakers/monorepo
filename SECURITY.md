# Security Policy

Report vulnerabilities privately to [pmuller+github@kolamayermakers.org](mailto:pmuller+github@kolamayermakers.org). Do not open a public issue for an exploitable vulnerability, credential exposure, or active-service weakness.

Reports should include affected paths, reproduction steps, impact, and any mitigation already attempted. Maintainers will acknowledge the report, coordinate a fix, and publish disclosure details after affected systems are protected.

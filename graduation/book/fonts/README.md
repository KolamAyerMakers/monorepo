# IBM Plex Mono

`IBMPlexMono-Bold.ttf` is the official IBM Plex Mono Bold font from
https://github.com/IBM/plex, revision
`763c36ef9117782905ae010056dfbe8fd2653a25`, path
`packages/plex-mono/fonts/complete/ttf/IBMPlexMono-Bold.ttf`.

The accompanying `OFL.txt` contains the upstream license (SIL Open Font License).
The font is vendored to make the cover export reproducible without installing
it globally. `fontconfig.xml` adds this directory to the Linux system fonts
for the Inkscape export only.

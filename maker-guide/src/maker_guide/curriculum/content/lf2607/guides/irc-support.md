# IRC Support

Use web IRC for live help and community, especially on Day 1:

[https://lf2607.kolamayermakers.org/irc/](https://lf2607.kolamayermakers.org/irc/)

Your IRC nickname is your classroom username. The server requires account authentication and does not let you change nickname away from that username.

## Channels

- `#kolamayermakers`: general workshop help and community.
- `#lf2607`: Linux Foundations course discussion.

## Guide Commands

- `!help <question>` asks the guide for help.
- `!thank nickname reason` thanks a classmate for specific help. You can send one thank-you each day; a valid thank earns the recipient +10 score. Read [scoring and rankings](scoring.md) for all limits and ranking rules.

## How To Ask For Help

Post the smallest useful version of the problem:

- What you tried.
- What happened.
- What you expected.
- Any short error text.

Use the web frontend first if terminal IRC setup is blocking you. Terminal IRC is a later challenge, not the Day 1 support path.

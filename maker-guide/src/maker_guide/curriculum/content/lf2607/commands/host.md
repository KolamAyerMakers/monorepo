# host

## Use

```bash
host lf2607.kolamayermakers.org
```

## What It Does

`host` asks DNS for a short, readable answer.

## Practice

Use it when `dig` is too verbose.

## Watch Out

DNS success only proves name resolution, not that a web service works.

## Docs Pointers

- Run `man host`.
- Read [DNS](../concepts/dns.md).

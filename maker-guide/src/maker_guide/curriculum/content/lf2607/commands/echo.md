# Command: `echo`

## Use

```bash
echo "hello makers"
```

## What It Does

`echo` prints its arguments followed by a newline.

## Practice

Use `echo` for quick interactive checks:

```bash
echo "$HOME"
echo "hello makers"
```

## Watch Out

Different shells disagree about `echo` options and backslash escapes. Use `printf` in scripts when output must be exact.

- Run `help echo`.

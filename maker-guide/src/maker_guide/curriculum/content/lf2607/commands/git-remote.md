# git remote

## Use

```bash
git remote -v
```

## What It Does

`git remote` manages named repository URLs such as `origin`.

## Practice

Use `git remote add origin <repo-url>` once, then verify with `git remote -v`.

## Watch Out

Remote names are labels. `origin` is common, not magic.

# ping

## Use

```bash
ping -c 3 google.com
```

## What It Does

`ping` tests whether a host responds and reports latency.

## Practice

Use `-c` so the command stops after a fixed number of packets.

## Watch Out

Some networks block ping. Failure does not always mean the website is down.

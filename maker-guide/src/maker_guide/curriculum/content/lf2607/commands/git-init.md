# git init

## Use

```bash
git init
```

## What It Does

`git init` creates a repository in the current directory.

## Practice

Run this from `~/src` to start your site's Git history.

## Watch Out

Check `pwd` first. Initializing git in the wrong directory creates confusion.

## Docs Pointers

- Read [git](git.md) and [git basics](../concepts/git-basics.md).
- Run `git help init`.

# dig

## Use

```bash
dig kolamayermakers.org
```

## What It Does

`dig` asks DNS questions and prints detailed answers.

## Practice

Look for the `ANSWER SECTION` first.

## Watch Out

DNS answers can be cached and can vary by resolver.

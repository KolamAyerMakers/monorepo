# htop

## Use

```bash
htop
```

## What It Does

`htop` shows running processes interactively, including CPU use, memory use, process ids, users, and command lines.

## Practice

Open it, sort by CPU or memory, inspect only your own processes, then quit with `q`.

## Watch Out

Do not kill processes you do not understand. On a shared server, focus on your own username.

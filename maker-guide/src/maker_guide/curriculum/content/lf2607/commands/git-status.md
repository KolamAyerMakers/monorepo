# git status

## Use

```bash
git status
```

## What It Does

`git status` tells you what changed, what is staged, and what is untracked.

## Practice

Run it before every commit.

## Watch Out

Untracked files are not in git until you add them.

## Docs Pointers

- Read [git](git.md), [git add](git-add.md), and [git diff](git-diff.md).
- Run `git help status`.

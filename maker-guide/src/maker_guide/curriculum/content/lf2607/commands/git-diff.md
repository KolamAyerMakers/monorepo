# git diff

## Use

```bash
git diff
```

## What It Does

`git diff` shows line-level changes that are not staged.

## Practice

Read your own diff before committing.

## Watch Out

After `git add`, use `git diff --staged` to see staged changes.

## Docs Pointers

- Read [git](git.md) and [diff](diff.md).
- Run `git help diff`.

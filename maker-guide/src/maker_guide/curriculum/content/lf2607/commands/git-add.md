# git add

## Use

```bash
git add README.md
```

## What It Does

`git add` stages changes for the next commit.

## Practice

Run `git status` before and after staging so you can see what changed.

## Watch Out

Staged does not mean saved forever. The commit saves the checkpoint.

## Docs Pointers

- Read [git](git.md), [git status](git-status.md), and [git commit](git-commit.md).
- Run `git help add`.

# git add

## Use

Start with the disposable repository from the [Git card](git.md), which creates `note.txt`. Run these commands inside that repository.

```bash
git add note.txt
```

## What It Does

`git add` stages changes for the next commit.

## Practice

Run `git status` before and after staging so you can see what changed.

## Watch Out

Staged does not mean recorded in history. A commit records the staged changes.

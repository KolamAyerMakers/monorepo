# fj

## Use

```bash
fj repo create src
```

## What It Does

`fj` creates and manages Forgejo repositories from the terminal. Your class account is already configured with a token.

## Practice

Create the empty `src` repository once, then add it as Git's `origin` and push your local `main` branch.

## Watch Out

Do not put tokens in commands, chat, or source files. If `src` already exists, inspect it in Forgejo instead of creating another repository.

# Command: `pwd`

## Use

```bash
pwd
```

## What It Does

`pwd` prints the current working directory of your shell.

## Practice

Run `pwd` when you are lost, before risky file operations, and after `cd` while learning.

## Watch Out

The current working directory is shell state. A new terminal, tmux pane, or script may start somewhere else.

## Docs Pointers

- Run `man pwd` and `help pwd`.

# xxd

## Use

```bash
xxd file.bin
```

## What It Does

`xxd` shows bytes in hexadecimal and ASCII columns.

It is useful when a file is not safe or meaningful to print with `cat`.

## Practice

Use it to inspect file headers.

## Watch Out

Hex output is low-level. Pair it with `file` first.

# git log

## Use

```bash
git log --oneline
```

## What It Does

`git log` shows commit history.

## Practice

Use `--oneline` when you want a compact view.

## Watch Out

Quit the pager with `q` if the log opens in `less`.

## Docs Pointers

- Read [git](git.md) and [git commit](git-commit.md).
- Run `git help log`.

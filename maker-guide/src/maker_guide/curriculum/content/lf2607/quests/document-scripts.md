# Document your scripts

Quest: document-scripts

## Mission

Create `~/scripts/README.md` that lists what your scripts do.

## Commands You Will Use

- `micro`
- `ls`
- `cat`

## Steps

1. List the scripts in `~/scripts`.
2. Create `~/scripts/README.md`.
3. Add a `# Scripts` heading.
4. Mention `hello.sh` and `info.sh`.

## Hints

1. Documentation is part of keeping scripts usable.
2. The heading should be plain Markdown.
3. Use `cat` to verify the README contents.

## If Check Fails

Make sure `~/scripts/README.md` contains `# Scripts`, `hello.sh`, and `info.sh`.

# Measure a ping

Quest: measure-ping

## Mission

Run `ping -c 3 google.com` and report the average round-trip time.

## Commands You Will Use

- `ping`

## Steps

1. Run `ping -c 3 google.com`.
2. Read the summary line at the end.
3. Find the average round-trip time.
4. Answer the guide with the value and `ms`.

## Hints

1. `-c 3` stops after three packets.
2. The average appears in the final timing summary.
3. Include `ms` in your answer.

## If Check Fails

Run the ping again and copy the average time from the summary line.

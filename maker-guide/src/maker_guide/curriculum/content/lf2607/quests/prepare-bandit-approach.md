# Prepare a Bandit approach

Quest: prepare-bandit-approach

## Mission

Write a short Bandit checklist using commands you already know.

## Commands You Will Use

- `ssh`
- `cat`
- `ls`
- `find`
- `grep`

## Steps

1. Review the first commands you use when a puzzle looks unfamiliar.
2. Include `ssh` for login.
3. Include `grep` for searching output or files.
4. Answer the guide with your first-command checklist.

## Hints

1. Start with login, listing, reading, finding, and searching.
2. Do not use commands that have not been taught yet.
3. Include both `ssh` and `grep` in your answer.

## If Check Fails

Answer with a short checklist that includes `ssh` and `grep`.

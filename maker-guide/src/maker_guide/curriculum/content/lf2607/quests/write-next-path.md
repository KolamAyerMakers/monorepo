# Write the next path

Quest: write-next-path

## Mission

Create `~/src/pages/next.md` describing what you will learn after S10.

## Commands You Will Use

- `micro`
- `build-website`
- `git add`
- `git commit`
- `git push`

## Steps

1. Create `~/src/pages/next.md`.
2. Add a heading that mentions Linux.
3. Write one concrete next action and when you will do it.
4. Rebuild the site.
5. Commit and push the page.
6. Ask the guide to check the source file.

## Hints

1. Choose one real next path, not five vague wishes.
2. Include the word `next` somewhere in the page.
3. The file needs a heading, Linux, and next-step language.

## If Check Fails

Open the file and add a Linux heading plus a concrete next step.

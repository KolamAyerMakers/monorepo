# Survive vim

Quest: survive-vim

## Mission

Use vim to create `~/playground/vim-note.txt`, then save and quit with `:wq`.

## Commands You Will Use

- `vim`
- `cat`

## Steps

1. Run `vim ~/playground/vim-note.txt`.
2. Press `i` and type one useful sentence.
3. Press Esc.
4. Type `:wq` and press Enter.
5. Run `cat ~/playground/vim-note.txt`.
6. Ask the guide to check the file.

## Hints

1. `i` enters insert mode.
2. Esc leaves insert mode.
3. `:wq` writes and quits.

## If Check Fails

Open the file again, add visible text, save with `:wq`, and confirm with `cat`.

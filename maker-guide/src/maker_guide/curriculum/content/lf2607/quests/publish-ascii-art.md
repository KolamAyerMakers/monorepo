# Publish ASCII art

Quest: publish-ascii-art

## Mission

Create `~/src/pages/art.md` with a fenced code block and rebuild.

## Commands You Will Use

- `micro`
- `build-website`

## Steps

1. Create `~/src/pages/art.md`.
2. Add a heading.
3. Put ASCII art inside triple backticks.
4. Run `build-website`.
5. Ask the guide to check the source file.

## Hints

1. Fenced code blocks preserve spacing.
2. Triple backticks open and close the block.
3. The file needs a heading and a fenced block.

## If Check Fails

Open the file and add missing triple backticks around the art.

# Explain sockets

Quest: explain-sockets

## Mission

Explain what host and port mean in a URL you checked with `curl -I`.

## Commands You Will Use

- `curl -I`

## Steps

1. Run `curl -I` against a URL.
2. Identify the hostname in the URL.
3. Identify where a port would appear.
4. Answer the guide using the words host and port.

## Hints

1. The host names the machine or virtual site.
2. The port selects the listening service.
3. HTTP defaults can hide the port number.

## If Check Fails

Answer again and explicitly mention both host and port.

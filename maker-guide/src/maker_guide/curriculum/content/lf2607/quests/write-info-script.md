# Write info.sh

Quest: write-info-script

## Mission

Create executable `~/scripts/info.sh` that runs `whoami`, `date`, and `hostname`.

## Commands You Will Use

- `bash`
- `chmod +x`
- `whoami`
- `date`
- `hostname`
- `micro`

## Steps

1. Create `~/scripts/info.sh` with a Bash shebang.
2. Put `whoami`, `date`, and `hostname` in the script.
3. Make it executable.
4. Run it.
5. Ask the guide to check the file.

## Hints

1. One command per line is fine.
2. Add labels with `printf` if you want clearer output.
3. The guide checks that all three commands are present.

## If Check Fails

Open the script and add any missing command.

# Compare DNS tools

Quest: compare-dns-tools

## Mission

Run both `dig kolamayermakers.org` and `host kolamayermakers.org`.

## Commands You Will Use

- `dig`
- `host`

## Steps

1. Run `dig kolamayermakers.org`.
2. Run `host kolamayermakers.org`.
3. Compare how much output each command prints.
4. Ask the guide to check your command history.

## Hints

1. `dig` prints detailed DNS sections.
2. `host` prints a shorter answer.
3. Run both exact commands before asking for a check.

## If Check Fails

Run both DNS commands exactly as listed.

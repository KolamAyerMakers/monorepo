# Reverse two arguments

Quest: reverse-two-arguments

## Mission

Create `~/scripts/reverse.sh` that prints `$2` before `$1`.

## Commands You Will Use

- `bash`
- `printf`
- `micro`

## Steps

1. Create `~/scripts/reverse.sh`.
2. Add a Bash shebang.
3. Print the second argument before the first argument.
4. Run it with two words.
5. Ask the guide to check the file.

## Hints

1. `$1` is the first argument.
2. `$2` is the second argument.
3. The file must contain `$2` before `$1`.

## If Check Fails

Move the output order so `$2` appears before `$1` in the script.

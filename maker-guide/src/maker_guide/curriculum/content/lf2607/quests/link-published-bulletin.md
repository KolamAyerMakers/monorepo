# Link the published bulletin

Quest: link-published-bulletin

## Mission

Link the generated report from `~/src/pages/index.md`, build the site, and inspect `~/public_html/singapore-today.html`.

## Commands You Will Use

- `build-website`
- `grep`

## Steps

1. Add a homepage link to `singapore-today.html`.
2. Build the site from its source.
3. Inspect the rendered page for every bulletin field, units, timestamp, and source.

Personalize the heading. The page is static output; a browser does not fetch live API data.

## Hints

1. Check both the source homepage link and the rendered page.

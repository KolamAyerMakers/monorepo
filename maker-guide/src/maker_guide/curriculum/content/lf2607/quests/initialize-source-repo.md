# Inspect your source repo

Quest: initialize-source-repo

## Mission

Inspect the seeded source repository with `git log` and `git status`.

## Commands You Will Use

- `git log`
- `git status`

## Steps

1. Run `cd ~/src`.
2. Run `git log --oneline`.
3. Run `git status`.
4. Ask the guide to check for the git repository.

## Hints

1. Check `pwd` before `git log`.
2. A git repo has a `.git` directory.
3. The guide checks for `~/src/.git`.

## If Check Fails

Move to `~/src` and inspect the `chore: seed astro site` commit.

# S4 Recap: Permissions And Git

Session: S4

## Core Idea

Linux is multi-user. Git is memory for your project.

## Remember

- `ls -l` shows permissions.
- Executable scripts need execute permission.
- `git status` tells you what Git sees.
- Commits are checkpoints you can explain.
- Forgejo is where your source becomes reviewable by another person.

## Live Core

If you attended live, you have the core milestone when your source repo is initialized, your first commit exists, generated output is ignored, and `git remote -v` shows the Forgejo `src` repository you pushed to.
